Połącz z repozytorium GitHub

Aby wgrywać zdjęcia, potrzebny jest osobisty token dostępu (Personal Access Token) z uprawnieniem do zapisu w repozytorium curlyheaddoodle-blip/curlyheaddoodle. Token jest zapisywany wyłącznie w Twojej przeglądarce (localStorage) i wysyłany tylko bezpośrednio do GitHuba — nigdzie indziej.

Jak zrobić token? (raz)
  1. Zaloguj się na GitHubie jako curlyheaddoodle-blip.
  2. Idź do Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. Utwórz token z dostępem tylko do repozytorium curlyheaddoodle, z uprawnieniem Contents: Read and write.
  4. Skopiuj token i wklej poniżej.

Zdjęcia na stronie

Wgraj zdjęcie dla każdej sekcji. Zostanie ono automatycznie przycięte i skompresowane, a strona pokaże je w ciągu minuty od zapisania.
